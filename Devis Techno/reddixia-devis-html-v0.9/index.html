Flux applicatif (corrigé)

Schéma Mermaid (syntaxe corrigée). Si une information manque, le titre l’indiquerait avec À confirmer.

flowchart LR
  U[Utilisateurs] -->|Demande| CS[Copilot Studio]
  CS --> HUB[IDEXIOS-HUB]
  HUB -->|Route| AG[Agents de domaine]
  AG --> DV[(Dataverse TPG\n(tpg_*))]
  AG --> SP[(SharePoint\nIdexios-Prime)]
  AG --> PA[Power Automate]
  HUB --> OUT[Sorties\nConversation • Power Pages • Livrables]
  OUT --> U

sequenceDiagram
  autonumber
  actor U as Utilisateur
  participant CS as Copilot Studio
  participant HUB as IDEXIOS-HUB
  participant A as Agent de domaine
  participant DV as Dataverse (tpg_*)
  participant SP as SharePoint (Idexios-Prime)
  U->>CS: Question / demande (rubrique)
  CS->>HUB: Contexte + conversation
  HUB->>A: Routage + consignes
  A->>DV: Lire/écrire données
  A->>SP: Lire gabarits / déposer livrables
  A-->>HUB: Résultats + indicateurs
  HUB-->>CS: Réponse + artefacts
  CS-->>U: Message + liens / cartes
