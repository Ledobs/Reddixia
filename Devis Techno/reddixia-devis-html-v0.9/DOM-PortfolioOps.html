Global

Le pack PortfolioOps regroupe les agents et modèles qui couvrent ce domaine. L’orchestration passe par IDEXIOS-HUB, qui applique les règles de routage et assemble les sorties.

Agents : 2
Données : Dataverse (tpg_*)
Référentiel : SharePoint Idexios-Prime

Agents du pack

  • ATHENA-PORT — Conseillère portefeuille : propose des analyses et recommandations sur la santé du portefeuille.
  • GAIA-RISK — Risque & dépendances : identifie signaux faibles, impacts, et mesures de mitigation.

BUS

  • Objectifs d’affaires, règles du domaine, responsabilités.
  • Décisions et recommandations produites pour le portefeuille.
  • Points d’intégration avec les autres packs.

Portefeuille — Santé & arbitrages Wrap‑up : synthèse portefeuille, statuts, priorités, recommandations.

1) Contexte métier

  • Scénario : un comité portefeuille demande une vue consolidée (avancement, risque, coût, capacité) pour arbitrer.
  • Besoin : décider rapidement (prioriser, stopper, financer) sur la base d’indicateurs traçables.
  • Process : Collecte données projets → Consolidation → Analyse → Recommandations → Diffusion.

Portefeuille — Risques & dépendances Wrap‑up : signaux faibles, impacts, plans de mitigation.

1) Contexte métier

  • Scénario : identifier risques cross-projets et dépendances qui menacent les jalons.

Portefeuille — Scénarios Wrap‑up : comparer options (priorités, capacité, coûts) et recommander.

1) Contexte métier

  • Scénario : “si on décale X / ajoute Y ressources, quel impact ?”.
  • Besoin : arbitrer avec transparence et traçabilité.
  • Process : Hypothèses → Simulation → Comparaison → Décision.

2) Données

  • Entrées : hypothèses, contraintes, capacité, budgets (À définir)
  • Sorties : tableau comparatif, recommandation, risques associés
