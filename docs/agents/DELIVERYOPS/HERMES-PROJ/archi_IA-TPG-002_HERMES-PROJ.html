Vue d’ensemble

Scénarios d’usage, contrat de sortie, et critères d’acceptation.

Scénarios d’usage

  • Question type (ex.) : « Donne-moi l’état du portefeuille pour le mois courant »
  • Drill-down : portefeuille → programme → projet → tâche
  • Restitution : résumé + preuves + actions proposées

Critères d’acceptation

  • Les filtres de contexte sont explicités (périmètre/période)
  • Les champs non disponibles sont signalés avec la raison
  • Les sorties sont reproductibles (mêmes entrées → même structure)
